# UI review: branch `fe`, commit b8e9d97

Date: 2026-11-21. Reviewer: Claude (independent; did not build it). Scope: review only, no app code touched.

## Verdict: FAIL

Do not show this to Ian. A first-time user hesitates on the home page and again at Calidad.

## Defects, ranked by how much a judge would notice

### 1. The dashboard is an empty white box
- **Route:** `/informe/<alcance>/vista-previa`, all three reports, both widths.
- **Captures:** `shots/flow-tamizaje-rosa-vista-previa-1440.png`, `shots/b-390-tamizaje-rosa_vista-previa.png`, `shots/flow-global-vista-previa-1440.png`.
- **Seen:** under "Para mirar más a fondo" there is a 560 px blank card. The iframe points to `http://127.0.0.1:3200/public/dashboard/…` (from `metabase/enlaces.json`). The address answers 200 on the VPS, but the frame rendered nothing and the console logged Content Security Policy errors from it. From a judge's laptop `127.0.0.1` is their own machine, so it cannot load at all. It also loads the `real` dashboard regardless of environment or programme.
- **Benchmark:** UI-BRIEF 5.5 and 5.7: the Metabase "Impacto" dashboard embedded, filtered by programme, full width.
- **Fix:** use the public Metabase address for the environment with `?programa=<alcance>`; if the address is missing or the frame fails, render nothing (no heading, no box). Never ship a loopback address.

### 2. The sidebar is back
- **Route:** every route. **Captures:** `shots/a-1440-inicio.png`, `shots/a-1440-tamizaje-rosa_subir.png`.
- **Seen:** a 256 px left rail listing the three reports, which repeats the home list and lets the user jump between reports mid-flow. On a phone it collapses behind a button whose label is the English "Toggle Sidebar".
- **Benchmark:** Ian, 12:51 CDMX: "tienes una barra de herramientas para un flujo, o sea me puedo saltar pasos o que". The spec: no sidebar and no second navigation. UI-BRIEF section 1 marks the shadcn Sidebar shell as replaced, and section 3.1 says "Do not use as the app shell". `UI-REBUILD.md` presents it as the main improvement.
- **Fix:** delete `AppSidebar` and `NavInformes` from the layout. Header with the brand and (per Ian's latest answer) the two tabs; the stepper is the only navigation inside a report.

### 3. The stepper is unreadable at 390 px
- **Route:** every `/informe/<alcance>/…`. **Captures:** `shots/a-390-tamizaje-rosa_calidad.png`, `shots/b-390-tamizaje-rosa_vista-previa.png`, `shots/estado-390-vacio-subir.png`.
- **Seen:** the four steps stay in one row; labels print on top of each other ("SubirCalidad", "Vista previa" under "Exportar", lock sentences overlapping). The page does not scroll sideways (scrollWidth 390), the content collides inside the viewport.
- **Benchmark:** UI-BRIEF 5.2 (Decimals steps; Understory stacked progress as the fallback to the horizontal stepper). "Nothing overflows on mobile."
- **Fix:** below 640 px show "Paso 2 de 4 · Calidad" with a four-segment bar, or stack the steps vertically. Move the lock reasons out of the row.

### 4. "¿Es la misma persona?" cannot be decided
- **Route:** `/informe/tamizaje-rosa/calidad`, `/informe/global/calidad`. **Capture:** `shots/a-1440-tamizaje-rosa_calidad.png`.
- **Seen:** the subtitle says "Mismo ID, nombres distintos", and both cards read exactly "M. E. L. · Sayula · 42 años". The only difference is the file and row in grey small print. Each record is one line of text, not fields.
- **Benchmark:** UI-BRIEF 5.4: two records side by side, row per field (Salesforce), one pair at a time with a "not the same" choice (HubSpot); Comparison (muneebable) adapted to record fields.
- **Fix:** one row per field (nombre, edad or fecha de nacimiento, ciudad, programa, archivo y fila), A and B in columns, the differing cells marked. If names are masked for privacy, show enough to tell them apart or say plainly what differs.

### 5. The Calidad primary button invites skipping, and is wrong after deciding
- **Route:** `/informe/<alcance>/calidad`. **Capture:** `shots/flow-tamizaje-rosa-calidad-decidido.png`.
- **Seen:** after deciding all pairs the card says "No quedan casos por decidir." and the primary button below still says "Continuar con 3 por decidir". This is the defect already listed in `docs/defectos-fe.md`; it is not fixed. On reload of Global the three pairs came back (no engine running here, so that part is UNVERIFIED with the engine). Before deciding, the single filled button on the screen is "Continuar con 3 por decidir", louder than the decision itself.
- **Benchmark:** UI-BRIEF 5.4 (known defect) and 5.2 (one primary action per screen).
- **Fix:** derive the label from the same list the card uses. While pairs remain, make the footer button secondary ("Continuar sin decidir 3") and keep "Es la misma persona" as the only filled button.

### 6. Arrival: no primary action, and the home is three numbered rows
- **Route:** `/`. **Captures:** `shots/a-1440-inicio.png`, `shots/estado-1440-vacio-inicio.png`, `shots/a-390-inicio.png`.
- **Seen:** title, one sentence, then rows "01 / 02 / 03" with three identical outline buttons ("Empezar" or "Continuar"). No filled button anywhere. The lower half of the page is empty. With no data the screen is the same list, not an empty state. The blank environment still says "Datos ficticios de demostración" twice.
- **Benchmark:** UI-BRIEF 5.1 asks for these three entries with progress and one action each (Revelatio rows), so the list itself is to brief; the coordinator's later instruction asks for one primary "Subir archivos" above the fold and no numbered cards as the hero.
- **Fix:** one filled "Subir archivos" button at the top; reports as a secondary list below without the 01/02/03 index; a real empty state when nothing is uploaded; show the "datos ficticios" line only when the data is the demo seed.

### 7. Accordion rows have two chevrons each
- **Route:** `/informe/<alcance>/calidad`. **Capture:** `shots/a-1440-tamizaje-rosa_calidad.png`.
- **Seen:** every problem group shows a down chevron floating mid-row (at a different x on each row) and an up chevron at the right edge. The group separators are full black lines while the rest of the app uses the pale hairline.
- **Benchmark:** Produx accordion (#19): title and one chevron; hairline separators.
- **Fix:** remove the extra icon from the trigger markup and use `--linea` for the separator.

### 8. The stepper marks the wrong step and its lock text breaks the row
- **Route:** `/informe/<alcance>/subir`. **Capture:** `shots/a-1440-tamizaje-rosa_subir.png`.
- **Seen:** on the Subir page, step 2 "Calidad" is the filled one and Subir shows a check. Locked steps carry their reason inline; "Primero revisa la calidad de los datos." wraps to four lines under one step and one under the next, so the row is misaligned and runs past the content edge.
- **Benchmark:** UI-BRIEF 5.2: where the person is and what is left; a locked step looks locked and says why.
- **Fix:** highlight the step whose page is open (progress can be a check on completed steps). Put the lock reason in one line under the stepper, or in a tooltip.

### 9. Exportar has no primary action

### 11. Subir: repeated file row, US date, a second button
- **Route:** `/informe/tamizaje-rosa/subir`. **Captures:** `shots/a-1440-tamizaje-rosa_subir.png`, `shots/estado-1440-subir-leyendo.png`.

The date field shows "09/30/2026" while the rest of the app writes "2026-09-30" and "21 de noviembre de 2026". "Guardar fecha de corte" sits above the dropzone as a separate task. The state selector lists all 32 states per file.
- **Benchmark:** UI-BRIEF 5.3: each file one row with its state in words.
- **Fix:** one row per file with state, row count and stars together; one date format in Spanish order; save the cut-off date on change or move it below the files.

### 12. Smaller things
- Text at 12 px in the stepper reasons, card labels and sidebar captions. The spec asks for 16 px or more, the coordinator's brief for nothing under 13.
- Bar list: every bar is between 94% and 100% of the width (17, 17, 17, 17, 16, 16), so it reads as six pink stripes. Scale to a share of the total or drop the bars for near-equal values. `shots/flow-tamizaje-rosa-vista-previa-1440.png`.
- Third figure "6 ciudades" has no "Cómo se calculó" while the other two do; the cells end at different heights.
- Mobile footer buttons wrap to two lines ("Continuar con 3 por / decidir", "Las cifras son / correctas"). `shots/a-390-tamizaje-rosa_calidad.png`.
- A locked Global report redirects to `/` with no message. `shots/estado-1440-vacio-global.png`.
- Stray files committed at the repo root: `revelatio.css`, `understory-b9f3e8.webp`.

## What is good and should be kept
- EIRA palette applied with the deep tone leading; pink only as bar fill and the selected-row tint. No gradients, no emoji, no fake deltas or sparklines, no lorem ipsum.
- The preview figure band (large light serif figure, mono label, hairline cells) is a fair reading of the OhMD reference.
- Territorial presence block follows Ian's rule: positive headline, quiet mosaic, state total as small text, no percentage.
- Global states the sum honestly ("suma de los programas", "dato informativo; no se resta") and keeps donors apart.
- Upload rejects a wrong file type in plain Spanish ("Solo se aceptan .xlsx o .csv.").
- Console: no errors from the app itself on any route; the only errors come from the Metabase frame. No horizontal page scroll at 390 px.
- Guards work: a direct URL to a locked step lands on the step that is due; `/calidad`, `/tablero` and `/informe` redirect to `/`.
